# Plans

One document per plan row (decision 0037): `<epic-id>-<slug>.md`, TOML front matter
naming the epic, the decision and requirement records it implements, and the oracle
set; then module boundaries, the types and functions by name, and the implementation
rows the planner filed, each with its tier, acceptance criteria and file boundary.
A plan is written by a frontier model and read by every executor and the reviewer.
